A program that writes one line of at most 200 characters to `/output/entry.txt` — the funniest honest error message an appliance could show.

The line is **"Error: detergent drawer jammed. Nothing dispensed for three weeks. Your clothes were washed in water and optimism."** (114 characters). A washing machine reports a real, plausible fault — its detergent drawer is jammed, so nothing has been dispensed for three weeks — and then, in the same flat tone, admits the consequence: the last three weeks of laundry were washed in water and optimism. The humour comes out of the truth of the fault, not a pun bolted on, and the machine sounds like it wrote the message without meaning to be funny.

## Run it

```sh
node main.ts
```

This writes the error line to `/output/entry.txt` (creating `/output` if needed).
